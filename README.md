# TikTok Downloader Bot

Telegram-бот на [aiogram 3](https://docs.aiogram.dev/), который скачивает видео и фото-слайдшоу из TikTok **без вотермарки** — работает через публичное API [tikwm.com](https://tikwm.com).

## Возможности

- Скачивание TikTok-видео без вотермарки
- Фото-слайдшоу (TikTok photo mode) — до 50 фото одним слайдшоу
- Поддержка коротких ссылок (`vt.tiktok.com`, `vm.tiktok.com`)
- Rich-сообщения: медиа, описание в сворачиваемом блоке и музыка приходят одним сообщением
- Музыка отдельным аудиоблоком — с названием, исполнителем и длительностью
- Личные режимы: каждый выбирает, что получать — только медиа, медиа и аудио, только аудио или чтобы бот спрашивал
- В группах вопрос «Хотите скачать с аудио?» приходит эфемерно — его видит только отправитель ссылки
- Премиум-эмодзи в интерфейсе и в инлайн-кнопках (для пользователей с Telegram Premium)
- Запасные способы отправки, если rich-сообщение недоступно
- Файлы стримятся напрямую в Telegram, ничего не сохраняется на диск сервера

## Как пользоваться

1. Открой TikTok
2. Выбери видео или фото
3. Нажми «Поделиться» → «Копировать ссылку»
4. Пришли ссылку боту

### Режимы — команда `/mode`

Команда доступна **только в личке с ботом**. Настройка у каждого пользователя своя и действует везде — и в личке, и в группах.

| Режим | Что присылает бот |
|---|---|
| ❓ Спрашивать каждый раз | После ссылки спрашивает «Хотите скачать с аудио?» с кнопками |
| 🎬 Только медиа | Видео или фото с описанием, без музыки |
| 🎬+🎵 Медиа и аудио | Всё сразу одним сообщением |
| 🎵 Только аудио | Один трек |

По умолчанию стоит «Спрашивать каждый раз» (меняется константой `DEFAULT_MODE` в `extras.py`). Если у поста нет отдельного звука, бот ничего не спрашивает и присылает медиа.

### Использование в группах

- Добавь бота в группу. Чтобы он видел ссылки, отключи режим приватности у [@BotFather](https://t.me/BotFather): `/setprivacy` → выбери бота → `Disable`. После этого удали бота из группы и добавь заново (или сделай администратором).
- Вопрос про аудио приходит эфемерным сообщением и виден только тому, кто отправил ссылку. Результат бот присылает в чат обычным ответом.
- Команда `/mode` в группах не отвечает — режим настраивается только в личке.

## Требования

- Python 3.11+
- **aiogram 3.31.0 или выше** — в нём есть rich-сообщения и эфемерные сообщения. В более старых версиях бот запустится, но будет присылать результат по-старому (альбомом или видео) и не будет задавать вопросы в группах.
- Премиум-эмодзи в кнопках работают, если у владельца бота есть Telegram Premium. Если Telegram их отклонит, кнопки придут с обычными эмодзи.

При запуске бот пишет в лог версию aiogram и поддержку возможностей:

```
aiogram 3.31.0 | rich messages: True | ephemeral messages: True
```

Если где-то `False` — обнови aiogram.

## Установка и запуск

### 1. Установи Docker (если ещё не установлен)

```bash
apt update
apt install ca-certificates curl gnupg
install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
chmod a+r /etc/apt/keyrings/docker.asc

echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] https://download.docker.com/linux/ubuntu \
  $(. /etc/os-release && echo "$VERSION_CODENAME") stable" | \
  tee /etc/apt/sources.list.d/docker.list > /dev/null

apt update
apt install docker-compose-plugin
```

Проверка:
```bash
docker compose version
```

### 2. Клонировать репозиторий

```bash
git clone https://github.com/Kisya123/Tiktok-saver-bot.git
cd Tiktok-saver-bot
```

### 3. Настроить токен

Создай файл `.env` в корне проекта:

```bash
echo "BOT_TOKEN=твой_токен_от_BotFather" > .env
```

Токен получить у [@BotFather](https://t.me/BotFather) командой `/newbot`.

### 4. Запуск через Docker (рекомендуется)

```bash
docker compose up -d --build
docker compose logs -f
```

В логах должна появиться строка `Start polling` без ошибок — бот запущен.

### 5. Запуск без Docker (альтернатива)

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python bot.py
```

### 6. (Опционально) Inline-режим

Чтобы бот работал через `@имя_бота ссылка` в любом чате — включи inline-режим у [@BotFather](https://t.me/BotFather):
```
/setinline
```
выбери бота, укажи любой placeholder-текст.

## Настройка

- **Премиум-эмодзи в кнопках** — словарь `BTN_ICONS` в начале `bot.py`. Чтобы узнать ID эмодзи, отправь боту сообщение с премиум-эмодзи — он ответит их ID.
- **Режим по умолчанию** — `DEFAULT_MODE` в `extras.py` (`ask`, `media`, `both` или `audio`).
- **Меню команд** бот настраивает сам при запуске: `/mode` только в личных чатах.
- **Личные режимы** хранятся в `user_modes.json` рядом с ботом. При пересборке Docker-контейнера файл пропадёт — чтобы сохранять настройки, примонтируй том к этому файлу.
